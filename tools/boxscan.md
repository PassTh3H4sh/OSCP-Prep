# boxscan

Replaces oscp-scan. Private repo: [PassTh3H4sh/boxscan](https://github.com/PassTh3H4sh/boxscan).

```bash
git clone git@github.com:PassTh3H4sh/boxscan.git ~/boxscan
cd ~/boxscan && chmod +x install.sh boxscan.py && ./install.sh

mkdir -p ~/boxes/<name> && cd ~/boxes/<name>
boxscan -t TARGET
```
